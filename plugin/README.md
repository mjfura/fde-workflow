# fde-workflow plugin for Claude Code

Marketplace with a plugin for working with FDE frameworks, best practices and workflow conventions for FDE roles.

## Install

In a Claude Code session:

```
/plugin marketplace add mjfura/fde-workflow
/plugin install fde-workflow@fde-workflow
```

## Skills

| Skill | Use it for |
|---|---|
| `fde-workflow:fde-workflow` | Marketplace with a plugin for working with FDE frameworks, best practices and workflow conventions for FDE roles. |
| `fde-workflow:setup` | Install and check what the plugin needs: the `fde-workflow` CLI |

Claude picks them automatically; you can also call them as slash commands.
