# fde-workflow-cli

Command line tool of the `fde-workflow` Claude Code plugin.

```sh
uv tool install fde-workflow-cli    # or: pipx install fde-workflow-cli
fde-workflow --version
fde-workflow doctor                 # checks that everything is ready
```

Requires Python 3.13 or newer. Source and plugin:
https://github.com/mjfura/fde-workflow
